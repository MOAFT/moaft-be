# 리뷰 지침

## 언어
- 모든 리뷰 코멘트는 한국어로 작성한다.
- 코드, 클래스명, 메서드명, 에러 코드 같은 식별자는 원문 그대로 둔다.

## 중요도 기준
다음은 반드시 지적한다.
- 잘못된 로직, 경계값 오류, NPE 가능성
- 보안 문제: 토큰·비밀번호·API 키 노출, 로그에 개인정보 출력, SQL 인젝션
- 다른 사용자의 기록에 접근할 수 있는 권한 검사 누락
- 트랜잭션 누락이나 잘못된 범위, N+1 쿼리

스타일, 네이밍, 리팩터링 제안은 사소한 의견으로만 남기고, 리뷰 한 번에 최대 3개까지만 남긴다.

## 항상 확인할 것
- `CLAUDE.md`의 컨벤션 위반 (`member` 사용, URL 형식 등)
- 새 에러 상황이 `ErrorCode`에 정의되어 있고 `BusinessException`으로 처리되는지
- 인증이 필요한 API에 인증·인가가 적용되어 있는지
- 응답 DTO에 엔티티를 그대로 노출하지 않는지

## 지적하지 않을 것
- CI가 이미 검사하는 빌드·테스트 실패
- `build/`, `out/`, `.gradle/` 아래 파일
